# 單篇精選卡

產出：一張 9:16 直式資訊圖卡，只講一集節目或一篇文章。繁體中文、台灣用語。版面 1080×1920、3x 截圖；交付 3240×5760 PNG（另留 1080×1920 版）。預設淺底深字；使用者說「深色版」才改深色。

和每日套件的差別：套件是「今天大家說了什麼」，這張是「這一集／這一篇完整在講什麼」，要讓沒聽過的人看完就懂主持人的論點、數字和他打算怎麼做。

## 1. 抓資料（Notion）

用 ToolSearch 載入 `mcp__Notion__notion-fetch`、`mcp__Notion__notion-query-data-sources`、`mcp__Notion__notion-search`。

| 類型 | 來源 | 取哪一筆 | 固定時間（台北） |
|---|---|---|---|
| 股癌 | `collection://5cc754e3-b559-4921-9413-bf050bbb3f72`（資料庫 `f9abd1b40ddf4b0485c46fe54168a559`） | 狀態＝已整理的最新一集 | 週三、週六 21:00 |
| All-In | `collection://020fbedb-8285-406f-9db7-1dd384506989`（view `https://www.notion.so/b6ed0133d4bf4cb38fdecca426430e79?v=6a8664abd8164fdfb4eae2c3dae54f3c`） | 類型＝主節目、狀態＝已整理的最新一集（名人專訪不算） | 週日 09:00 |
| FOMO KP | Substack 訂閱筆記 `collection://d9a690dc-5f2a-4654-9d02-0ac89e9a8d26`，標題含「FOMO KP」 | 最近兩天內的長文 | 有長文當天 19:30 |

- 查詢先用 SQL（`ORDER BY "date:日期:start" DESC LIMIT 3`）；回 usage_limit_reached 就改用 view 模式，不要重試。
- 目標那一筆的日期若超過 3 天前（代表本週新集還沒進 Notion）：不要拿舊集充數，回覆「最新一集是 M/D 的，尚未有新集」，排程執行時就此結束。
- FOMO KP：標題含「Notes」或標示「僅可見開頭／僅部分內容」的短記不做。兩天內沒有長文就回覆「沒有新的長文」並結束。
- fetch 該頁，讀「30 秒重點」「投資人重點」「關鍵數據」「風險」。逐字稿不必讀；摘要有疑義時才查逐字稿對應段落。
- 同一張卡已存在於「每日圖卡」（同來源、同集數或同標題）就不重做，回覆已做過。

## 2. 編輯原則

- 大標兩行：這一集／這一篇最核心的判斷，關鍵詞用 `<em>` 主色；副標一行交代集數、來賓或文章原題。
- 區塊（依內容取捨，由上到下）：
  1. **關鍵數字**：4–6 格 KPI，只用筆記裡有的數字，不自行換算。
  2. **主要論點**：3–5 點，編號，每點一句粗標＋一到兩句說明，寫明是誰的看法。
  3. **一個圖**：從內容挑最能說明論點的一種——堆疊橫條（金額組成對照基準）、位階線、時間軸、情境三層框、小長條。沒有適合的數字就不硬畫。
  4. **他打算怎麼做**：主持人或作者自己的操作、部位、條件（例如「暫避晶片股」「費半未站回月線前不加碼」）。
  5. **風險與反方**：筆記的風險段，加上內容裡自己承認的不確定。
  6. **接下來看什麼**：有明確日期的事件，未發生的用虛線圓點。
- 口述內容寫成「主持人認為／作者估」，不寫成事實。筆記標「ASR／待確認／推測／未查證／陰謀論」的照標 `<span class="tag">`。
- 業配段落不上圖。涉及個人私事的爆料細節不放，只留對市場與公司治理的影響。
- 首次出現的台股個股附代號。
- 頁尾：左「來源：Notion ○○筆記（節目口述／作者觀點，未另查證）」，右「非投資建議」。

## 3. 設計系統

`base.css`、`render.py`、輸出與檢查流程完全沿用 **daily-av-two-pack** 技能（同一套字型、字級、元件與 3x 截圖；淺色主題的追加樣式也相同）。本技能只多三組色票：

淺色（預設）：
- 股癌：`--bg:#fbf6f3;--card:#ffffff;--line:#ecd8cf;--ink:#1f100b;--ink2:#35221c;--mute:#6b554d;--acc:#b3261e`，badge「癌」，光暈 #ffd2c4 右上、#f5e2b8 左下
- All-In：`--bg:#f6f4fc;--card:#ffffff;--line:#dad5ee;--ink:#120e26;--ink2:#27223f;--mute:#57526f;--acc:#5b3fd0`，badge「A」，光暈 #d9d0ff 右上、#c9e0fb 左下
- FOMO KP：`--bg:#f2f9f9;--card:#ffffff;--line:#cde3e4;--ink:#081a1c;--ink2:#1c3134;--mute:#4b6265;--acc:#00707a`，badge「KP」（字級 22px），光暈 #bdeaec 右上、#d5dcf7 左下

深色（指定時）：底色改各自主色的極深色（如 #140a08、#0c0a18、#071214），卡片再亮一階，主色改亮（#ff6b5e、#a590ff、#4fd6de），其餘照 daily-av-two-pack 的深色做法。

若工作環境沒有 daily-av-two-pack 技能：告訴使用者需要先安裝它，不要自己另起一套版型。

## 4. 輸出

- 檔名：`YYYY-MM-DD_股癌_EP###`、`YYYY-MM-DD_AllIn_E###`、`YYYY-MM-DD_FOMOKP`，各存 `_3240.png` 與 `_1080.png`；日期用節目或文章的日期。
- 用 SendUserFile（display: render）送出 3240 版，讓使用者在對話裡直接看到圖。
- 檢查：content height ≤ 1920、沒有孤字換行、圖表標籤不重疊、底部留白 ≤150px（不足就從筆記補一個論點或數字）。

## 5. 歸檔與回覆

- 寫入 Notion「每日圖卡」`collection://26c6b4e4-c29a-4e27-b7a2-6557e285a6db`：標題 `YYYY-MM-DD｜來源｜大標`、日期、套件＝單篇精選卡、來源＝股癌／All-In／FOMO KP、主軸、發文文案（3–5 行，結尾「非投資建議」）、發布狀態＝待發。選項不存在時先用 update-data-source 新增。圖檔能上傳就附 3240 版，傳不上去就留空並在回覆說明需手動拖入。
- 回覆：一句說這張是哪一集／哪一篇、主軸是什麼；列出圖上標了「未查證／ASR」的地方；提醒 LINE 傳送選原始畫質。
- 排程（無人值守）執行時不發問，照上面的規則自行判斷，並在回覆第一行寫明做了哪一筆或為什麼沒做。
